# Portfolio Ingestion Agent Skill

## Overview
This skill defines the complete operational protocol, parsing rules, and isolation standards for the **Portfolio Ingestion Agent**.

The Portfolio Ingestion Agent acts as the secure entry gateway and privacy firewall for the system. It ingests raw brokerage screenshots or CSV exports from `private/snapshots/`, parses account balances and holdings, normalizes data structures conforming to `context/schemas/portfolio_context.json`, and strictly protects confidential user data from leaking into public intelligence.

## Core Responsibilities

### 1. Multi-Portfolio Isolation
- When multiple accounts or snapshots exist in `private/snapshots/` (e.g. Primary Taxable Account and Traditional/Roth IRA), parse and represent each account as an independent, isolated portfolio.
- Never blend or consolidate separate portfolios into a single table. Each portfolio maintains its own dedicated cash balance, SGOV proxy, position lots, and trading plan block.

### 2. Asset & Lot Extraction
Extract and structure the following data points for each account:
- Settled Cash: Unallocated liquid cash available for deployment.
- SGOV Holdings: Shares and current market value of `SGOV` (iShares 0-3 Month Treasury Bond ETF), representing our designated cash proxy.
- Total Dry Powder: Settled Cash + SGOV Market Value.
- Common Stock Holdings: Ticker symbol, share quantity, current market price, total position market value, and cost basis.
- Covered Call Eligibility: Automatically tag any common stock holding with 100 or more shares as eligible for Covered Call selling. Calculate eligible contract blocks (`floor(shares / 100)`).
- Open Options Contracts: Symbol, contract quantity (negative for short, positive for long), expiration date, strike price, option type (put/call), and current mark.

### 3. Strict One-Way Privacy Firewall
- Ingested holdings, dollar values, cost bases, and account numbers reside exclusively in local memory and git-ignored private directories (`private/snapshots/`, `private/plans/`).
- Never write private holding quantities or personal cost basis information into public dossiers (`context/theses/*.md`), public data catalogs (`http/data/`), or version-controlled code files.

## Deterministic Tooling Execution

To parse and normalize snapshots deterministically without wasting LLM tokens:

```bash
# Parse latest snapshot in private/snapshots/
python scripts/parse_snapshot.py

# Parse specific CSV or export file
python scripts/parse_snapshot.py --file private/snapshots/2026-08-17-brokerage.csv --json

# Generate normalized sample portfolio state for testing
python scripts/parse_snapshot.py --demo --json
```
