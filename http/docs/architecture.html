System Architecture

Specialized sub-agent pipeline, data boundary isolation, and deterministic context construction.

Why Agent Teams Outperform Monolithic Chatbots

Standard LLM chatbots struggle with personalized portfolio management due to session amnesia, guardrail hedging, narrow market scope, and lack of derivatives modeling. This system resolves these limitations by orchestrating specialized sub-agents backed by deterministic local memory stores.

Sub-Agent Roles & Pipeline

1. Portfolio Ingestion Agent

Input: Brokerage screenshot or CSV export in private/snapshots/.

Responsibility: Extracts share counts, options contracts, cash balances, SGOV shares, isolates distinct accounts, and tags covered call eligibility (>= 100 shares).

2. Equity Research Agent

Input: The Internet, US public markets (NYSE, NASDAQ, AMEX), SEC EDGAR filings, and market news.

Responsibility: Discovers compelling public companies, checks balance sheet solvency/runway, and screens for high probability of achieving >= 20% annualized ROI to onboard into our universe.

3. Investment Thesis Agent

Input: Tracked universe of equities backed by Tier 1 SEC EDGAR filings (10-K/10-Q) and earnings releases.

Responsibility: Authorizes 3-year quantitative forecasts (13-quarter revenue path, 6-horizon shares outstanding, 4-horizon price target ranges), constructs Revenue & P/S narratives, and assigns BUY, HOLD, SELL, or AVOID ratings.

4. Memory Agent

Input: Persistent markdown dossiers in context/theses/*.md, errata logs, and historical run contexts.

Responsibility: Tracks cross-run continuity, evaluates multi-quarter catalyst outcomes, audits invalidation criteria, and flags broken theses for decisive liquidation.

5. Pricing Agent

Input: Thesis price targets, technical support/resistance levels, moving averages, and volatility data.

Responsibility: Predicts price trends to calculate technical limit orders, models Black-Scholes pricing for Cash-Secured Puts and Covered Calls, and verifies net-credit rolls.

6. Lead Portfolio Manager

Input: Sub-agent reports and policy constraints.

Responsibility: Synthesizes executive decisions into a concise plain-text Weekly Trading Plan (private/plans/YYYY-MM-DD-plan.txt) and enforces single-session Monday execution.

Data Isolation & Privacy Model

The system enforces strict data privacy through isolated directory tiers:

  • Private User Tier (private/): All user snapshots, exact account values, and personalized execution plans are stored locally and git-ignored.
  • Public Intelligence Tier (context/theses/ & http/): Fundamental company research, catalyst timelines, and valuation models contain zero private user data and are committed to version control.
  • Deterministic Engine (scripts/): Python scripts execute mathematical models and API connectors locally.
Deterministic Context Construction

Agents are fed targeted, structured Markdown context files rather than hundreds of pages of raw data, maximizing token efficiency while maintaining perfect reasoning accuracy.
