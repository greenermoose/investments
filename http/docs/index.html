Audience Segmentation Architecture

This repository organizes code and data cleanly by primary consumer to ensure zero ambiguity and maximum operational efficiency:

Target Audience Directory Format & Purpose
AI Agents context/ High-density Markdown prompts, persistent thesis memory dossiers, and strategy rules.
Humans (Public Web) http/ & http/docs/ Responsive HTML/JS companion dashboard, documentation, universe cards, and options tools.
CLI & Deterministic Automation scripts/ Python utilities for Black-Scholes options pricing, SEC EDGAR scraping, and universe caching.
Humans (Private Data) private/ Confidential brokerage snapshots and simple plain ASCII text trading plans (git-ignored).
Developer Sandbox scratch/ Local sandbox for temporary exploratory scripts and test calculations (git-ignored).
Privacy & Local Execution

All sensitive account snapshots and weekly trading plans are stored locally under private/, which is excluded from source control. Public company intelligence and research are tracked in context/theses/ and displayed under http/.
