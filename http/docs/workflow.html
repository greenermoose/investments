Weekly Workflow & Execution Protocol

The operational cadence connecting weekend portfolio ingestion, agent deliberation, executive reporting, and Monday market-open order placement.

Weekly Cadence & Timeline

1. Weekend Snapshot

Timing: Saturday / Sunday

User places a fresh brokerage screenshot or CSV export into private/snapshots/.

2. Multi-Agent Deliberation

Timing: Sunday Evening

Ingestion parses holdings → Memory reviews theses → Screener evaluates new ideas → Derivatives specialist models limits.

3. Executive Plan Generation

Timing: Sunday Night

Lead Portfolio Manager writes the weekly trading plan to private/plans/YYYY-MM-DD-plan.md.

4. Monday Execution

Timing: Monday 9:30 AM ET

User reviews the plan, conducts Q&A if desired, and enters the specified limit orders into their brokerage.

Weekly Trading Plan Structure

Every generated plan in private/plans/ follows a strict, actionable Markdown format:

# Weekly Trading Plan: 2026-08-17

## Executive Action Summary (Monday Open Limit Orders)
| Action | Symbol | Strategy | Strike / Limit | Expiration | Collateral / Value |
| :--- | :--- | :--- | :--- | :--- | :--- |
| SELL TO OPEN | AAPL | CSP | $210.00 Put @ $2.45 Limit | 2026-09-18 | $21,000.00 SGOV |
| SELL TO OPEN | MSFT | CC | $460.00 Call @ $4.10 Limit | 2026-09-18 | 100 Shares |

## Active Position Thesis & Catalyst Review
- Detailed review of all holdings vs. earnings catalyst calendar.

## New Trade Rationales & Invalidation Rules
- Explicit investment thesis, valuation model, and sell rules for new proposals.
Plain Text & Markdown Simplicity

Trading plans in private/plans/ are strictly plain text or standard Markdown. They do not require any web build or server to read, keeping confidential personal execution records clean, durable, and portable.
