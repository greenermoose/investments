Weekly Workflow & Execution Protocol

The operational cadence connecting weekend portfolio ingestion, agent deliberation, executive reporting, and Monday market-open order placement.

Weekly Cadence & Timeline

1. Weekend Snapshot

Timing: Saturday / Sunday

User places a fresh brokerage screenshot or CSV export into private/snapshots/.

2. Multi-Agent Deliberation

Timing: Sunday Evening

Ingestion parses holdings → Memory reviews theses → Screener evaluates new ideas → Derivatives specialist models limits.

3. Executive Plan Generation

Timing: Sunday Night

Lead Portfolio Manager writes the weekly trading plan to private/plans/YYYY-MM-DD-plan.txt in human-centric plain text.

4. Monday Execution

Timing: Monday 9:30 AM ET

User reviews the plain-text plan, conducts Q&A if desired, and enters the specified limit orders into their brokerage in a single session.

Weekly Trading Plan Structure

Every generated plan in private/plans/ is strictly plain ASCII text. It avoids hard-to-read Markdown pipe tables in favor of structured ASCII headers, clear indentation, sequential portfolio sections, and step-by-step numbered order blocks:

Plain Text Standard & Execution Principles

Trading plans in private/plans/ are strictly plain ASCII text. Never use Markdown tables or ambiguous choices. Every position has a decisive recommendation, single-session execution, deterministic contingencies, and automated Friday settlement.
