User Guide & Operational Cadences

Complete operational procedures, token economy rules, CLI commands, and playbooks for human traders and autonomous AI agents.

Core Operating Philosophy: Parsimonious Token Spend & "Trust But Verify"

Running unconstrained whole-universe LLM queries on every market tick is cost-prohibitive and introduces hallucination drift. This system enforces a strict division of labor: deterministic scripts execute math, price syncs, onboarding, and schedule projections at 0 LLM tokens, while generative AI agents are invoked selectively for qualitative synthesis, thesis authoring, and single-session weekly deliberation using verified cached data.

The 6 Tiered Operational Cadences

Operational workflows are partitioned into six distinct cadences ranging from intraday zero-token price updates to on-demand universe expansion and rare ground-truth reconciliations from primary SEC filings:

Cadence 1: Daily 0 Tokens

Market Prices & Technical Volume Refresh

Daily synchronization of live share prices, trading volumes, 20/50-day moving averages, and 52-week support/resistance bounds to screen for buyable dips and limit triggers.

Cadence 2: Weekly ~2K - 5K Tokens

Weekly Deliberation & Trading Plan

Single-session weekend portfolio snapshot ingestion, Black-Scholes options limit calculation, and decisive plain-text Monday execution plan synthesis in private/plans/.

Cadence 3: Event-Driven ~500 - 1.5K Tokens

Press, Sentiment & Short Seller Surveillance

Surveilling corporate press wires, Reddit investor chatter (r/stocks, r/wallstreetbets), and reports from 20 top activist short sellers to catch thesis friction early.

Cadence 4: Scheduled ~500 Tokens / Stock

SEC Filing Anticipation & XBRL Ingestion

Tracking statutory 10-Q and 10-K filing deadlines, projecting company filing windows, and ingesting authoritative audited financial facts within 24 hours of release.

Cadence 5: On-Demand ~10K - 15K / Stock

Coverage Universe Expansion & Onboarding

Screening US markets for compounders targeting >= 20% annualized ROI, ingesting SEC XBRL filings, modeling multi-horizon valuations, and onboarding single or batch equities on demand.

Cadence 6: Rare / Audit Full Audit Mode

Full Ground-Truth Source Regeneration

End-to-end rebuild and reconciliation directly from original Tier 1 primary sources (SEC EDGAR XBRL APIs, exchange feeds, Form NPORT-P fund filings) to purge stale state and guarantee 100% accuracy.

Operational Playbooks & CLI Tool Instructions

Cadence 1

Frequent Daily Price & Volume Updates (0 LLM Tokens)

Because stock prices and trading volumes fluctuate every market session, run the live price fetcher daily before market open (9:00 AM ET) and after close (4:30 PM ET):

# Ingest live market prices and 30-day candles across the entire universe
python scripts/fetch_market_prices.py --live

# Refresh a specific target watchlist during intraday market action
python scripts/fetch_market_prices.py --symbols NVDA AAPL MSFT TSLA AMZN --live

# Screen for high-conviction opportunities (>= 20% annualized ROI) at current prices
python scripts/screen_market.py --min-roi 20.0 --exclude-avoid

This updates context/data/market_prices.json and http/data/market_prices.json deterministically without consuming any LLM tokens.

Cadence 2

Weekly Deliberation & Monday Execution Plan

Execute the weekly single-session deliberation workflow over the weekend:

  1. Export account holdings as CSV or screenshots into private/snapshots/.
  2. Prompt your AI agent with the protocol in context/prompts/weekly_deliberation.md.
  3. Open the generated plain ASCII plan in private/plans/YYYY-MM-DD-plan.txt.
  4. Execute all specified limit orders at Monday 9:30 AM ET market open in one sitting.
# Test snapshot parsing deterministically
python scripts/parse_snapshot.py --json

# Run Black-Scholes options pricing calculator for target strikes
python scripts/calculate_pricing.py --symbol NVDA --stock-price 218.17 --strike 200.0 --dte 35 --option-type put

# Generate plain ASCII trading plan from parsed snapshot state
python scripts/generate_plan.py --save
Cadence 3

Event-Driven Press, Sentiment & Short Seller Surveillance

Surveil breaking news, emerging investor friction themes on Reddit, and reports from 20 influential short sellers:

# Inspect high and medium severity investor concern themes across the universe
python scripts/surveil_sentiment.py --concerns-only

# Deep dive into sentiment polarity and press headlines for target tickers
python scripts/surveil_sentiment.py --symbols NVDA TSLA ENPH PLTR --json

# Check whether a candidate company has active short seller campaigns or reports
python scripts/track_short_sellers.py --symbol SMCI

# Review all 20 influential activist short seller research firms and track records
python scripts/track_short_sellers.py --list-firms

If an activist short report is published, follow context/prompts/sentiment_and_short_seller_surveillance.md to determine if the report mandates thesis invalidation or creates a high-margin-of-safety buyable dip.

Cadence 4

Scheduled SEC Filing Anticipation & XBRL Ingestion

Track upcoming 10-Q and 10-K filing windows and ingest audited statements as they are submitted:

# Audit filings due in the next 30 days based on statutory deadlines
python scripts/anticipate_sec_filings.py --upcoming-days 30

# Inspect imminent filings due in the next 14 days
python scripts/anticipate_sec_filings.py --status IMMINENT_NEXT_14_DAYS

# Ingest authoritative SEC EDGAR XBRL facts for newly filed companies
python scripts/fetch_sec.py --symbols NVDA CRM WDAY --live

# Re-aggregate TTM revenues, share counts, and master catalogs
python scripts/build_universe_json.py
Cadence 5

On-Demand Coverage Universe Expansion & Onboarding

When you want to screen the market for new 20%+ ROI compounders or add any number of additional public equities to coverage on demand:

# 1. Onboard a single named equity (live SEC EDGAR XBRL statements & market feeds)
python scripts/onboard_company.py --symbol CRWD --live

# 2. Onboard a batch of multiple equities simultaneously
python scripts/onboard_company.py --symbols NOW ABNB NET MDB --live

# 3. Screen market for >= 20% ROI candidates in a sector and auto-onboard top N
python scripts/onboard_company.py --screen --min-roi 20.0 --sector Technology --limit 3

# 4. Screen existing universe for >= 20% ROI candidates (analysis mode)
python scripts/screen_market.py --min-roi 20.0 --exclude-avoid

# 5. Run full quality control audit to assert 0 errors / 0 warnings across all universe files
python scripts/quality_control.py --audit

See System Workflows for prompt templates to trigger this workflow through your AI agent.

Cadence 6

Rare Ground-Truth Regeneration & Full Anti-Hallucination Audit

When you want to regenerate all repository intelligence directly from original primary sources to eliminate any chance of hallucination or parameter drift:

# 1. Fetch fresh master CIK directory and live SEC EDGAR XBRL statements
python scripts/fetch_sec.py --live

# 2. Re-ingest live market closing prices and rebuild historical price archive (18mo)
python scripts/fetch_market_prices.py --live
python scripts/fetch_market_prices.py --archive

# 3. Synchronize QQQ, DIA, and SPY constituents from SEC Form NPORT-P filings
python scripts/fetch_etf_holdings.py

# 4. Refresh sell-side analyst price targets and coverage registry
python scripts/fetch_analyst_targets.py --live
python scripts/build_analyst_registry.py

# 5. Compile off-balance sheet footnote liabilities (leases, pensions, commitments)
python scripts/build_off_balance_sheet_data.py

# 6. Re-synthesize master catalogs, SEC calendar, sentiment, and short campaigns
python scripts/build_universe_json.py
python scripts/anticipate_sec_filings.py
python scripts/surveil_sentiment.py --seed
python scripts/track_short_sellers.py --seed

# 7. Execute complete deterministic Quality Control audit to assert 0 errors / 0 warnings
python scripts/quality_control.py --audit

Key Execution Rules & Portfolio Safety Constraints

Zero Ambiguity Policy

The system never presents open-ended dilemmas or "choose X or Y depending on your risk tolerance". Every position receives a single, high-conviction recommendation.

Deterministic Contingencies

If market conditions fluctuate at market open, the plan provides instant deterministic branching (Branch A vs Branch B) so you never need to improvise.

Multi-Portfolio Isolation

Distinct accounts are analyzed independently. Orders for Portfolio 1 are executed completely before moving to Portfolio 2.

100% Collateralized Derivatives

Strictly NO option buying and NO naked selling. Every put sold is 100% cash-secured (or SGOV-backed); every call sold is 100% covered by common shares.
